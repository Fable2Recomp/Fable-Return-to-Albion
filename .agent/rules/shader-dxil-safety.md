# D3D12 / Intel Arc DXIL Shader Safety Rules

When authoring or modifying any shader (`.gdshader`, `.gdshaderinc`, `.glsl`) or host code that feeds shaders (`Godot/src/`):

1. **Zero `discard;` in ALL Forward+ `PASS_MODE_COLOR` (`!MODE_RENDER_DEPTH`) & `canvas_item` Shaders (`godot#118719` / `#120857` / `PR #122994`)**: Because Mesa's `nir_to_dxil` in Godot 4.7 lacks `nir_opt_peephole_select`, any `if (cond) { discard; }` compiles to a divergent basic-block branch around `dx.op.discard(i1 true)` that hangs Intel Arc D3D12 when followed by clustered `while (merged_mask != 0)` loops (`decals`, `reflection_probes`, `omni_lights`, `spot_lights`). Under `#if CURRENT_RENDERER == RENDERER_FORWARD_PLUS`, **never** emit `discard;` in color-pass spatial or `canvas_item` shaders:
   - `depth_draw_never` / `canvas_item` blended shaders output the hardware blend identity (`ALBEDO = vec3(0.0); ALPHA = 0.0;` or `COLOR = vec4(0.0);`).
   - Depth-writing alpha-cutout spatial shaders (`standard_material_body.gdshaderinc`, `fur_shell.gdshaderinc`, `standard_material_phong.gdshader`, `tree_canopy.gdshader`, `entity_highlight_silhouette.gdshader`) declare `render_mode depth_prepass_alpha;` (so Godot's internal `USE_OPAQUE_PREPASS` discards only inside `MODE_RENDER_DEPTH`, which has zero `while` loops), output `ALPHA = should_discard ? 0.0 : ...;` in `PASS_MODE_COLOR`, and draw at `RenderPriority = -16` ahead of semi-transparents at `0` (`fur_shell_depth` writes `DEPTH = should_discard ? 0.0 : FRAGCOORD.z;`). Only `ShadowsOnly` casters (`shadow_caster.gdshader`, `shadow_caster_cutout.gdshader`) and `depth_prepass_marker.gdshader` may keep `discard;`.
2. **Never Wrap `dFdx`/`dFdy` in `if (!IN_SHADOW_PASS)`**: In Godot 4.7 Forward+, `IN_SHADOW_PASS` expands to a runtime UBO bit (`bool(scene_data_block.data.flags & SCENE_DATA_FLAGS_IN_SHADOW_PASS)`), not a compile-time `#define`. Wrapping derivatives in `if (!IN_SHADOW_PASS)` strips nothing at compile time and breaks uniform quad derivative control flow. Always compute `dFdx`/`dFdy`/`fwidth`/`geom_cross` unconditionally at the very top of `fragment()`, before any branch or loop, and use explicit `textureGrad(...)`, `textureLod(..., 0.0)`, `texelFetch(...)`, or `fable_normal_side_precomputed(...)` inside branches.
3. **No `OmniLight3D.ShadowMode.DualParaboloid`**: Always use `OmniLight3D.ShadowMode.Cube` (`placed_shadow_limit`: `1/2/4/8`, enabled across all 4 presets including `Low`). `SHADOW_DUAL_PARABOLOID` injects an early `dp_clip` `discard;` before user `fragment()`. Use `shadow_caster_solid.gdshader` and `shadow_caster_cutout.gdshader` for non-fading `ShadowProxy` casters.
4. **Gate Heavy Math Behind `if (!should_discard)` & Guard `void light()` Without `return;`**: Do not burn parallax, PBR/ORM/normal fetches, soft-depth fades, lighting setup, or emission math on culled pixels. Wrap heavy `fragment()` stages in `if (!should_discard)` with outputs safely zero-initialized, and guard `void light()` on `ALPHA > 0.0` (never `return;` inside `light()`).
5. **No Dynamic Vector Component Indexing (`OpVectorExtractDynamic`)**: Never dynamically index vectors (`vec4[i]`) or construct small local indexed arrays inside shader loops when explicit channel selectors or unrolled edge comparisons apply cleanly, and avoid runtime-indexed constant lookup arrays (use branchless ALU formulas like `fable_bayer_threshold` where trivial).
6. **Guard Projective `/ w` Divisors**: Before dividing any reconstructed view/world vector by `.w` (`inv_proj * ndc`), clamp/guard the divisor (`abs(w) > 1e-6 ? w : 1e-6`) so sky (`depth == 0.0`) or unbound depth texels cannot inject `Inf`/`NaN` into FP16 targets.
7. **Explicit Sampler Defaults & Fallback Globals**: Every non-global `sampler2D` / `sampler2DArray` (except `hint_screen_texture`, `hint_depth_texture`, `samplerCube`) must carry `hint_default_*` or `hint_normal`. Global texture parameters must be bound to a valid 1x1 `ImageTexture` fallback (never empty `new Texture2Drd()`).
